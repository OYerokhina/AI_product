# components

Окремі елементи інтерфейсу до складання в систему: картка клієнта,
рядок етапу, пігулка статусу, елемент таймлайну, форма нотатки.

Кожен компонент описується станами, а не одним виглядом:
default / active / overdue / completed / disabled / loading / empty.

Стан «прострочено» тут головний — саме він несе основну роботу інтерфейсу.
