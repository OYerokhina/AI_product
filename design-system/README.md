# design-system

Зібрана система: токени + компоненти + правила їх поєднання.
Те, чим користуються при малюванні нових екранів.

Містить: сітку й відступи, типографічну шкалу, ієрархію кнопок,
патерни списків, порожні стани, стани помилок, правила темної теми.

Обидві теми — рівноправні, темна не «додається потім».
