# tokens

Єдине джерело правди для кольорів, типографіки, відступів і радіусів.

- `tokens.json` — значення у нейтральному форматі
- З нього генеруються `ThemeExtension` для Flutter і змінні для Figma

Правило з `../CLAUDE.md`: кольори у віджетах — тільки через токени,
ніколи літералами. Якщо потрібного токена немає — додати сюди, не хардкодити.
