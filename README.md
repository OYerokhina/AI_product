# TheBrain

Мобільний планер для фахівців, які ведуть клієнтів через повторювані зустрічі —
коучів, тренерів, репетиторів, консультантів, нутриціологів.

Тримає контекст по кожному клієнту, показує план роботи й підказує, що зробити сьогодні.

## Навіщо

Фахівець із 10–30 активними клієнтами тримає контекст у голові, нотатках і месенджерах.
Перед зустріччю треба згадати: на якому ми етапі, що обіцяли, що клієнт просив урахувати.
TheBrain робить цю пам'ять зовнішньою.

## Ключові можливості

- **Воркфлоу по клієнту** — процес розбито на етапи з дедлайнами; з пресету або з нуля
- **Нотатки й фідбек після етапу** — те, що треба підняти перед наступною зустріччю
- **Таймлайн зустрічей** — уся історія роботи з клієнтом в одній стрічці
- **Щоденні підказки** — екран «Сьогодні» з діями по всіх клієнтах і ранковий дайджест
