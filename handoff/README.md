# handoff

Те, що передається в розробку: специфікації екранів, поведінка станів,
анімації, крайні випадки, експортовані ассети.

Обов'язково для кожного екрана:
- поведінка при порожньому списку
- поведінка при помилці мережі й офлайні
- що відбувається при довгих іменах і великій кількості клієнтів
- обидві мови (EN / UK) — українська довша, макет має витримати
