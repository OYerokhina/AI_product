# concept

Візуальний напрям: 2–3 концепти ключового екрана в кольорі й типографіці.
Мета — обрати мову продукту до того, як малювати всі екрани.

Вихідна точка — напрям із `../CLAUDE.md` §8: тихий професійний інструмент,
тепла нейтральна база, індиго-акцент, семантика статусів робить основну роботу.

Обраний концепт фіксується тут із коротким обґрунтуванням вибору.
