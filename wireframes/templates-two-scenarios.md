# Мої шаблони: два сценарії

Ескіз 2026-10-04. Закриває дефект **3.2** з критики в
[`../sitemap.md`](../sitemap.md): один екран робить дві різні речі.

Домовленість була — вирішується ескізом, не обговоренням. Ось ескіз.

---

## Що саме порівнюємо

| | Сценарій A | Сценарій B |
|---|---|---|
| **Job** | R7 почати сьогодні | R1 переграти план |
| **Звідки приходить** | «Вибір шляху» при заведенні клієнта | Режим «переграти план», посеред роботи |
| **Що обирає** | **Шаблон цілком** | **Один крок** із будь-якого шаблону |
| **Стан людини** | Нічого не почато, можна подумати | Посеред незбереженої перебудови |
| **Результат** | План заповнено, перехід до плану | Крок додано, **повертається туди ж** |

Головна відмінність не в даних, а в **одиниці вибору**: шаблон проти кроку.

---

## Сценарій A — застосувати шаблон цілком

Людина щойно завела клієнта. Нічого ще не почато, поспіху немає,
рішення варте перегляду.

```
┌──────────────────────────────────┐
│  ←   Мої шаблони                 │
├──────────────────────────────────┤
│                                  │
│  МОЇ                             │
│  ┌────────────────────────────┐  │
│  │ Підготовка до ЗНО          │  │
│  │ 8 кроків · ~3 місяці       │  │
│  │ застосовано 4 рази         │  │
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ Розмовний курс             │  │
│  │ 12 кроків · ~6 місяців     │  │
│  └────────────────────────────┘  │
│                                  │
│  ГОТОВІ ПРЕСЕТИ                  │
│  ┌────────────────────────────┐  │
│  │ Репетиторство, семестр     │  │
│  │ 10 кроків · ~4 місяці      │  │
│  └────────────────────────────┘  │
│                                  │
│  ──────────────────────────────  │
│  Скласти з нуля              →   │
│                                  │
└──────────────────────────────────┘
```

Тап по шаблону відкриває перегляд — застосовувати наосліп не можна:

```
┌──────────────────────────────────┐
│  ←   Підготовка до ЗНО           │
├──────────────────────────────────┤
│  8 кроків · старт сьогодні       │
│                                  │
│   1  Діагностика          сьогодні│
│   2  План навчання          +3 дні│
│   3  Базова граматика      +10 днів│
│   4  Розмовна практика     +24 дні │
│   …                               │
│   8  Пробний іспит         +80 днів│
│                                  │
│  Терміни рахуються від дня       │
│  застосування                    │
│                                  │
│  ┌────────────────────────────┐  │
│  │        Застосувати         │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

**Чому саме так.** «8 кроків · ~3 місяці» на картці відповідає на головне
питання вибору — чи підходить цей шаблон цьому клієнту. «Застосовано 4 рази»
піднімає нагору те, чим вона справді користується.

## Сценарій B — узяти один крок

Людина посеред перебудови. На екрані незбережені зміни, і втратити їх
не можна. Їй потрібен **крок**, а не шаблон.

```
┌──────────────────────────────────┐
│  ✕   Переграти план              │
├──────────────────────────────────┤
│  ▒▒ пройдене, не змінюється ▒▒   │
│  ✓ 1  Діагностика                │
│  ✓ 2  План навчання              │
│  ✓ 3  Базова граматика           │
│  ──────────────────────────────  │
│  ПОПЕРЕДУ                        │
│    4  Розмовна практика      ✕   │
│    5  Есе                    ✕   │
│                                  │
│  + крок                          │
├──────────────────────────────────┤
│ ╭──────────────────────────────╮ │
│ │  Додати крок із шаблону   ✕  │ │
│ │  ┌────────────────────────┐  │ │
│ │  │ 🔍  пошук кроку        │  │ │
│ │  └────────────────────────┘  │ │
│ │                              │ │
│ │  ПІДГОТОВКА ДО ЗНО           │ │
│ │   Пробний іспит           +  │ │
│ │   Розбір помилок          +  │ │
│ │                              │ │
│ │  РОЗМОВНИЙ КУРС              │ │
│ │   Співбесіда англійською  +  │ │
│ │   Презентація проєкту     +  │ │
│ ╰──────────────────────────────╯ │
└──────────────────────────────────┘
```

**Чому аркуш, а не екран.** Перебудова не збережена. Повноекранний перехід
забирає її з контексту й створює ризик утратити зміни — рівно той тупик,
який ми прибирали правилом виходу.

Аркуш лишає перебудову на екрані за собою. Можна додати кілька кроків
підряд, не закриваючи, і вийти одним тапом.

**Чому кроки пласким списком із пошуком.** Їй потрібен конкретний крок,
а не шаблон, у якому той крок живе. Змушувати відкривати шаблон, щоб дістати
один пункт, означає додати два тапи до кожної дії всередині петлі перебудови.
Назва шаблону лишається заголовком групи — як підказка про походження,
не як рівень навігації.

## Рішення

**Одне джерело даних, дві поверхні.**

| | Сценарій A | Сценарій B |
|---|---|---|
| Поверхня | Повний екран «Мої шаблони» | Аркуш «Додати крок із шаблону» |
| Одиниця | Шаблон | Крок |
| Подання | Картки з обсягом і частотою | Плаский список кроків із пошуком |
| Вихід | Перехід у план клієнта | Повернення в перебудову |

Це не «два режими одного екрана» і не «два окремі екрани».

**Два режими** змусили б запихати перегляд шаблону в момент, коли людина
стоїть посеред незбереженої роботи.

**Два екрани** означали б дві копії того самого списку шаблонів, які
доведеться підтримувати окремо.

Правильна рамка — **одна бібліотека, показана з різною деталізацією**:
повний екран для вибору шаблону, аркуш для вибору кроку.

### Що це міняє в документах

- `sitemap.md`: до екрана «Мої шаблони» додається **аркуш «Додати крок
  із шаблону»** — не окремий екран, а поверхня в межах режиму перебудови.
- `flows.md`, потік R1: вузол «Мої шаблони» стає аркушем. Повернення
  в режим перебудови, а не перехід далі.
- Дефект 3.2 закрито.

### Чого цей ескіз не вирішує

**Чи потрібна бібліотека кроків** — окрема сутність для кроків поза
шаблонами. Рішення від 22 вересня лишається: не заводимо, сигнал до перегляду
— якщо люди масово створюють шаблони з одного кроку.

Аркуш у сценарії B працює й без неї: кроки беруться з наявних шаблонів
і групуються за ними.
