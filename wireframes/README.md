# wireframes

Структура екранів без кольору й стилю. Відповідають на питання
«що на екрані і що головне», не «як це виглядає».

Порядок: спочатку ключові сценарії, потім периферія.

Ключові сценарії:
1. Ранок — «Сьогодні», що робити по всіх клієнтах
2. Перед зустріччю — відкрив клієнта, підняв контекст за 5 секунд
3. Після зустрічі — закрив етап, записав нотатки й фідбек
4. Новий клієнт — вибір пресету або воркфлоу з нуля
