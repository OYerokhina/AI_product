# research

Доказова база продукту. Усе, що ми **дізналися**, а не припустили.

- `research.md` — головний документ, 4 секції: КОНКУРЕНТИ, БЕНЧМАРК, ПАТЕРНИ, ВИСНОВКИ
- `screens/` — скриншоти чужих застосунків, референси інтерфейсів
- `entry-patterns.md` — п'ять патернів введення після зустрічі й вибір під наш контекст
- `personas.md` — три гіпотези-персони, зібрані з ринкових доказів; інтерв'ю не проводились
- `jtbd.md` — jobs у форматі «коли / хочу / щоб»; непідкріплені винесено в Гіпотези

Правило: кожне продуктове рішення в `../CLAUDE.md` має спиратися або на висновок
звідси, або на явно позначену гіпотезу.
